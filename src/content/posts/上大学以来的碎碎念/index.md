37天的旅程，是开始，也是告别

# 入学
走入xx校园（目前还是不想吐露学校，但盒出来应该还是比较轻松的），新鲜感绝对是有的

占地2000多亩地，无论东西还是南北都长到仅用脚步无法丈量

忙来忙去，经过一天的安顿，总算是收拾的可以容身

接下来便是各种各样的开学仪式：从院系，到学校……

随着“军训动员大会”的召开，也逐渐吹响了了军训的号角

# 军训
感觉升入大学做的第一件正确的事情就是加入了政工组（

一开始冲旗的时候有点忙，后面几乎每天任务量很少，剩下时间就可以用来自习
（果然听学长经验有好处）

在军训的时候快速简单过了一遍（真的是很潦草，仅仅了解一下概念之类的）高数上需要学的东西，和cs61A的一大半

没有很积极地参与军训，因此留下来的印象自然也不是很深刻（除了动员大会后那场**雨），也仅仅只有20km拉练与军训晚会吧

军训就这么潦草地结束了

# 开学
然后就正式开始上课了

大学——大不了自己学

以转专业为目标的话，大一上可以说仅有两件事吧：学积分，相关经历

在经过了numerous查看和搜索学校论坛后，决定：

1、在大一上学期狠狠刷学积分

2、抽空学习一下相关课程

## 学积分
果然大学的学积分看起来组成明确但实际操作起来真的很难搞

各种奇奇怪怪的影响因素，远远不只是平时的考试了

除了高数、线代受期末期中考试 的影响极其大之外，其他的科目的平时分占比都很大

目前正在及其头秃ing

还有万恶的工程实践（神奇的评分规则导致昨天的项目拿了个B+）


# 同学关系

天天去图书馆导致被同学狠狠吐槽（


# 展望？回望？

时不时睡在床上的时候还会回忆起高中的时候

假如高考没有失误呢？假如oi再多拿那一个test case呢？假如……

可惜都是假如

看着高中时发的那一篇篇充满幻想的期待，更加难以忍受

今天是9/30 舍友都陆陆续续回家了

现在的我正坐在图书馆里敲下这一行行文字

不想也不敢回家放松，害怕放松过后迎接我的是更大的失败

高考的失利似乎让我无法真正的融入进大学生活，也像那次大学学院聚餐的时候同学说的那句“别再做高中生了”

我也想能真正地融入大学生活，去聚餐，去参加各种各样之前从未参加过的活动，或者是和舍友在宿舍**无所顾虑**地吹吹水，打打游戏；而不是像现在一样，整天在图书馆里，为高数和线代那一道题目而疯狂准备，为了可能的那零点几个绩点而忧心忡忡

效率即使不高也比玩耍更强吧，我如是安慰自己

前段时间，高中同学群里还搞怪发这样的文字

![微信图片](https://js.histcat.top/gh/histcat/static@master/images/%E5%BE%AE%E4%BF%A1%E5%9B%BE%E7%89%87_2026-09-30_142754_528-20260930-245324.png)

绝大多数人可能都只是看作笑话，可我却真的有种想再次回去，让上天再给我一次机会的冲动

可惜复读的压力还是太大……今年高中还大改，回去后估计更加难以适应

正如“在概率崩塌之前，一切都悬而未决”

我们永远无法在结果结束之前，真正地了解到当前所做的一切究竟是正确与否

那就把大一当成高四吧，看看概率的天平是否会倾斜到成功的那一侧

谨以此文，记录当下

告别过去，迎接未来

再也不敢立下誓言，害怕迎接的又是失败

那就希望一切朝着更好的方向进展吧

希望明年的同一时间，能够迎接安心的、顺心如意的十一假期

能够去往自己真正想要投身的方向
